# Employee Manager – QA Portfolio Project

A QA testing project created to demonstrate practical skills in manual testing, test case design, API testing and test automation.

## Application

Employee Manager is a simple employee management application used as the system under test.

The project focuses on testing employee creation and validation of employee data.

## Testing Scope

The current testing scope includes:

- Name field validation
- Salary field validation
- Age field validation
- Position field validation
- On leave field
- Functional testing
- API testing
- Test case design
- Test execution and reporting

## Test Management

TestRail was used to create, organize and execute functional test cases.

### TestRail Results

- **29 test cases**
- **28 Passed**
- **1 Blocked**
- **0 Failed**
- **97% pass rate**

Test cases were organized into functional sections and designed using:

- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)
- Decision Table Testing
